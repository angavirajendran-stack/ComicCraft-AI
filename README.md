### 🚀 Features
- **🎨 AI Art Generation** - Gemini Flash & Pro powered panel creation
- **📖 Auto Story to Panels** - Converts text to comic layout automatically
- **📄 PDF Export** - Export comics as PDF
- **⚡ FastAPI Backend** - High-performance API
- **🎭 Premium UI** - Dark theme, responsive design

### 🛠️ Tech Stack
- **Backend:** FastAPI, Python
- **AI:** Google Gemini Flash / Pro
- **Frontend:** HTML5, CSS3, JavaScript
- **Export:** ReportLab PDF
